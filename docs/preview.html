ICSS → a CSS-like theme engine for iced

Style Rust desktop apps with class lists, variables, and pseudo-states. The HTML below is a visual mockup of how the corresponding iced widgets render at runtime — same theme tokens, same class names.

Buttons

Variants compose with size modifiers. Hover, active, and disabled states resolve from iced Status.

RUST · iced 
let t = &state.theme;

button(text("Save"))   .style(t.button(&["button", "primary"]));
button(text("Delete")) .style(t.button(&["button", "danger"]));
button(text("More…"))  .style(t.button(&["button", "default", "small"]));
button(text("+"))      .style(t.button(&["button", "primary", "round"]));
ICSS · theme.icss 
.button { color: #fff; border-radius: 8px; padding: 8px 16px; }
.primary          { background-color: var(--primary); }
.primary:hover    { background-color: var(--primary-light); }
.primary:disabled { background-color: #333; color: rgba(255,255,255,0.4); }
.button.primary   { box-shadow: 0 2px 8px rgba(0,0,0,0.25); }
.small            { border-radius: 6px; padding: 4px 10px; }
.round            { border-radius: 9999px; }

Form controls

Inputs, checkboxes, togglers, and radios share the sz-md / sz-sm / sz-xs sizing tokens so font, padding, and gap stay in lockstep.

Sign in This field is required
RUST · iced 
let md = t.sizing(&["sz-md"]);   // font, padding, gap

text_input("Email", &state.email)
    .size(md.font_size).padding(md.padding())
    .on_input(Msg::Email)
    .style(t.text_input(&["input", "sz-md"]));

checkbox(state.accept).label("Accept terms")
    .size(md.font_size).text_size(md.font_size).spacing(md.gap)
    .on_toggle(Msg::Accept)
    .style(t.checkbox(&["checkbox", "sz-md"]));

toggler(state.telemetry).label("Enable telemetry")
    .on_toggle(Msg::Telemetry)
    .style(t.toggler(&["toggle"]));
ICSS · theme.icss 
.input {
    background-color: var(--surface-raised);
    border: 1px solid var(--border);
    border-radius: 8px;
    color: var(--text);
}
.input:focus { border-color: var(--primary-light); }
.input.error { border-color: var(--danger); }

.checkbox:checked { accent-color: var(--primary); }
.toggle:checked   { background-color: var(--primary); }

A small set of iced widgets that don't ship in core, styled entirely through ICSS.

RUST · iced 
use icss_widgets::DataTable;

let table = DataTable::new(&state.hosts)
    .column("Host",    |h| t.text(&h.name, &["body-small"]))
    .column("Status",  |h| status_badge(t, h.status))
    .column("Latency", |h| t.text(&h.ping, &["body-small", "text-soft"]))
    .sortable(true).page_size(20);

table.view(t)   // theme-aware — no inline styling needed

Putting it together

A complete sign-in panel — no inline colors, no hand-rolled style closures.

RUST · iced 
t.frame(
    t.column(&["subsection"])
        .push(t.text("Sign in", &["title-medium"]))
        .push(email_input(t, &state.email))
        .push(password_input(t, &state.password))
        .push(remember_checkbox(t, state.remember))
        .push(
            t.row(&["row"])
                .push(button(text("Cancel")).style(t.button(&["button", "default"])))
                .push(button(text("Sign in")).style(t.button(&["button", "primary"])))
        ),
    &["section", "section-body"],
